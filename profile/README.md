## ✦ Who we are

**VProgrammers** is an independent software development studio focused on building and delivering mobile applications for international clients. Our work spans native iOS and Android development, Kotlin Multiplatform, integrations, and production releases.

We favor **native user experiences**, **practical architecture**, and **maintainable code** over unnecessary complexity.

<table>
<tr>
<td width="33%" valign="top"><h3>📱 Native mobile</h3>Swift, SwiftUI, UIKit, Kotlin and Jetpack Compose — experiences tailored to each platform.</td>

<td width="33%" valign="top"><h3>🚀 Delivery</h3>API integrations, authentication, notifications, testing, publishing and ongoing improvements.</td>

## ✦ How we build

```text
Product idea → Platform strategy → Architecture → Development → Release → Iterate
```

- **Native-first UX:** Respect platform conventions and performance expectations.
- **Share with purpose:** Reuse business and data logic where it genuinely reduces duplication.
- **Built to evolve:** Prefer clear boundaries, testable components and practical maintainability.
- **Production matters:** Consider offline behavior, integrations, compatibility and release stability.
